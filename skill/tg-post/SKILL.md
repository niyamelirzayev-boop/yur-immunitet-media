# Telegram-пост с обложкой — «Юридический иммунитет»

Эталон — пост про льготные ставки УСН (v4, 20.11.2026), одобрен Камилой как «супер». Пиши так же.

## 1. Порядок работы

1. Факты: найди 2–3 источника (WebSearch, mode extended). Официальные (sozd.duma.gov.ru, pravo.gov.ru, nalog.gov.ru) — когда есть, плюс деловые СМИ (Ведомости, РБК, Клерк, Прайм). Уточни статус: проект + чтение / принят / подписан / действует / слух. Если источники расходятся в цифрах — так и скажи в посте.
2. Напиши пост по структуре и стилю ниже (HTML).
3. Сделай обложку (раздел 4).
4. Отправь в бот на просмотр: chat_id `1343438066` (личный чат Камилы с @pravoimmunitet_bot), через Zapier → Telegram. Первой строкой пометка `📝 ПОСТ <тема> · v<N>` и `———` (в канал эти строки не идут).
5. Жди «ок» от Камилы **в чате с Claude** (ответы в боте не видны). Правки — новая версия v<N+1> в бот.
6. После «ок» публикуй в `@yur_immunitet` тем же способом, без служебной пометки. Не больше 2–3 постов в день.

## 2. Структура поста

```
<эмодзи темы> <b>Хук-заголовок с болью и сарказмом</b>
<штамп> · <статус подробно> · 🔥 Индекс боли N/5

Абзац «как сейчас» (2–3 предложения, ирония в скобках).

Абзац «что меняется» (номер законопроекта/закона, главное — <b>жирным</b>).

<blockquote>✅ <b>Кому повезло:</b> …

❌ <b>Кому нет:</b> …</blockquote>

Абзац «что это значит в деньгах» — пример расчёта; самую болезненную цифру — в <tg-spoiler>.

Абзац «надежда / подвох» (что ещё может поменяться).

<b>Что делать уже сейчас:</b>
— пункт;
— пункт;
— пункт (мы тоже следим и поменяем штамп…).

<blockquote expandable>🔎 <b>Для дотошных:</b> расхождения в источниках, детали, оговорки.

🔗 Источники: <a href="…">Ведомости</a> · <a href="…">Клерк</a> · <a href="…">Прайм</a></blockquote>

<i>Провокационный вопрос аудитории, сталкивающий мнения (две стороны)</i> 👇

#что_изменилось #<тема>
```

Штампы: 🟢 ПРИНЯТО / ДЕЙСТВУЕТ · 🔴 ПРОЕКТ (+ какое чтение и дата) · ⚫ СЛУХ.
Хештеги рубрик: #что_изменилось #слух_недели #канцелярит #ошибка; тем: #ип #усн #самозанятые #авто #жильё #права #банки #мрот.

## 3. Стиль — что Камила одобрила и что запретила

ДА:
- Полные, живые, разговорные предложения. Сарказм и ирония — в **скобках**: «(просто в их регионе так было всегда)», «(а маржа у торговли и так не резиновая)», «(то есть квартал по новой ставке заплатить всё равно придётся)».
- Хук с болью: «Платили 1% по УСН? С 2027 года, скорее всего, придётся платить 6%».
- Много конкретики: номер законопроекта, цифры «было/станет», кто выиграл/проиграл, расчёт в рублях, сроки.
- Ссылки на источники в каждом посте.
- Форматирование Telegram (HTML, format=html): `<b>` жирный — ключевая мысль; `<u>` подчёркнутое — цифры и даты; `<s>` зачёркнутое — «было» (<s>1%</s> → <b>6%</b>); `<tg-spoiler>` — самая болезненная цифра/вывод; `<blockquote>` — списки «кому повезло / кому нет»; `<blockquote expandable>` — детали и источники; `<i>` — финальный вопрос.
- Финал — вопрос, который сталкивает две стороны (предприниматели vs покупатели, работники vs работодатели) и провоцирует спор в комментариях.

НЕТ:
- Рубленые фразы из одного-двух слов с точкой («Мимо.», «Сразу.», «На руки меньше. Сразу.») — выглядит искусственно.
- Клише вроде «Налоговая не забывает».
- «Пишите, разберём», «юристы ответят», «задайте вопрос» — мы не консультируем, только слушаем мнения.
- Канцелярские блоки «Что изменилось / Кого касается» заголовками.
- Шутки над конкретными чиновниками/политиками, политические оценки, советы нарушать закон. Факты — только проверенные.

Длина: 1500–2200 знаков (лимит Telegram-сообщения 4096).

## 4. Обложка

- Размер 1280×720 (PNG), фирменный стиль: `assets/brand.css`, шаблон `assets/cover-template.html`.
- На обложке: логотип «Юридический иммунитет», жёлтый тег темы (`УСН · 2027`), одна крупная мысль (цифры «было → стало» или короткий хук из 2–5 слов), подпись 1 строка до ~70 знаков (max-width 660px), штамп статуса в правом нижнем углу (st-red ПРОЕКТ / st-grn ПРИНЯТО / st-ink СЛУХ). Фон чередуй: dark / light / yellow / red.
- Рендер: скопируй шаблон и brand.css в папку поста, поправь текст, затем `node assets/render-cover.js <папка> 720` (рендерит section в slide-01.png, viewport 1280×720; Playwright уже установлен). Переименуй в cover.png.
- Обязательно открой картинку и проверь: штамп не налезает на текст, нет переносов «15 / млн» (ставь &nbsp;), текст не вылезает.

## 5. Отправка картинки вместе с постом

Telegram-бот принимает картинку только по публичной HTTPS-ссылке; подпись к фото ≤ 1024 символов, а пост длиннее. Поэтому:
- Хостинг — публичный репозиторий GitHub `niyamelirzayev-boop/yur-immunitet-media` (клон: /home/user/yur-immunitet-media; если его нет — add_repo + `git clone --depth 1`). Кладём обложку в `covers/ГГГГ-ММ-ДД-<тема>.png`, коммитим и пушим в main, проверяем `curl -s -o /dev/null -w "%{http_code}"` → 200. Ссылка: `https://raw.githubusercontent.com/niyamelirzayev-boop/yur-immunitet-media/main/covers/<файл>.png`. Скилл тоже хранится в репозитории (`skill/tg-post`) — после правок копируй его туда и пушь.
- Пост отправляем одним сообщением со «скрытой ссылкой» на обложку: в самом начале текста `<a href="URL_ОБЛОЖКИ">&#8203;</a>` и `disable_link_preview: false` — Telegram покажет обложку превью. Если превью не появилось — отправь `send_photo` с обложкой и сразу за ним пост `send_message` (disable_link_preview true).
- Если публичной ссылки нет — отправь пост текстом, а обложку пришли Камиле в чат через SendUserFile и прямо скажи, что картинку в Telegram прикрепить не удалось.
